Install ByteOS

The easiest path is the live ISO plus byte-install. The installer takes about a minute.

Read this first. ByteOS installs to a whole disk and erases everything on it. Use a spare disk, a USB stick, or a virtual disk. Do not select the disk that holds your current operating system.

What you need

  • A PC that can boot legacy BIOS or CSM mode (UEFI-only machines need CSM enabled).
  • An ATA/IDE disk. AHCI, NVMe, and USB storage are not supported by the installer.
  • A USB stick for the live ISO, or a virtual machine.
  • At least 32 MiB free on the target disk. 64 MiB or more recommended.

Step 1: Download the ISO

Get ByteOS.iso from the GitHub releases page. If you build from source, run .\build.ps1 and use the ISO in the project root.

Step 2: Write the ISO to USB

  • Rufus (Windows): choose the ISO, select GPT or MBR as required by your firmware, and write in DD mode if offered.
  • balenaEtcher: select the ISO and the USB stick, then Flash.
  • Linux/macOS: sudo dd if=ByteOS.iso of=/dev/sdX bs=4M status=progress where /dev/sdX is the whole USB disk, not a partition.

Step 3: Boot the live environment

Open the firmware boot menu, choose the USB device, and make sure the system boots in legacy BIOS/CSM mode. ByteOS starts at a byteos> prompt. This live environment is read-only; the disk is untouched until you run the installer.

Try the live commands:

fetch
start-desktop
donut

Step 4: Run byte-install

byte-install

The installer asks for:

  1. Installation disk - pick the number of the spare ATA disk. Check the model and size.
  2. Username - 1 to 31 characters; letters, digits, dot, dash, underscore.
  3. User password - typed twice, hidden with asterisks.
  4. Root password - typed twice, hidden with asterisks.
  5. Hostname - press Enter for byteos.
  6. Confirmation - type INSTALL in capitals.

The installer writes the MBR, stage 2, kernel, ByteFS partition, this website, and your account database, then flushes the disk and offers a reboot.

Step 5: Boot from the disk

Remove the USB stick (or detach the ISO in your VM), then boot the machine again. ByteOS shows a login screen. Sign in with the username and password you created. The root account is available with su.

Test it in QEMU

Create a spare virtual disk, boot the ISO with that disk attached, and install:

qemu-img create -f raw byteos-disk.img 64M

qemu-system-x86_64 -m 1024 -smp 4 \
  -cdrom ByteOS.iso \
  -drive file=byteos-disk.img,format=raw,if=ide \
  -boot d

Inside the live console:

byte-install

Choose disk 1, create your account, and confirm. Then shut down and boot the installed disk:

qemu-system-x86_64 -m 1024 -smp 4 \
  -drive file=byteos-disk.img,format=raw,if=ide \
  -boot c

Troubleshooting

  • The installer lists no disks. The disk must be visible as a legacy ATA/IDE device. In QEMU use -drive ...,if=ide. On real hardware, enable IDE/legacy storage mode if the firmware offers it.
  • The machine will not boot after install. Check that the firmware is in BIOS/CSM mode and that the target disk is first in the boot order. ByteOS does not support UEFI boot yet.
  • The installer refuses the disk. You selected the disk ByteOS is currently running from. Boot the ISO and install to a different disk.
  • The browser shows a URL instead of a page. This is expected for external links; ByteOS has no network stack.

Prefer to prepare a disk yourself? See the manual installation guide.
