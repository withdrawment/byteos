A 64-bit operating system you can read end to end.

ByteOS boots from its own hand-built El Torito ISO and MBR, enters long mode with no GRUB and no libc, and gives you a console, a classic text desktop, a 640x480 graphical desktop with a mouse, a keyboard-driven tiling window manager, a local web browser, a file explorer, a text editor, and an installer.

What is inside

fetch

A fastfetch-style system summary with shaded 3D torus ASCII art, CPU, memory, uptime, boot mode, disk, and account details.

Three desktops

Enter start-desktop and choose the classic text-mode ByteDesktop, ByteWin 95 (a genuine 640x480 VGA GUI with a mouse, icons, draggable windows, a native Fetch window, command history, a starfield screensaver and a Start menu), or ByteTile, a dwm-style tiling window manager with nine tags, three layouts, Super shortcuts, a built-in HTML browser, a full terminal, and an editable /bytetile.conf.

Linux-style shell

lsblk, df, mkdir, cd, pwd, touch, rm, uname, date, uptime, and echo join fetch, donut, and the rest.

Local web browser

Reads HTML files from ByteFS and renders headings, paragraphs, lists, links, and preformatted text. This website ships inside the OS.

byte-install

An archinstall-style guided installer. Pick an IDE or AHCI SATA disk, create a user, set the user and root passwords, and write a bootable system.

Editors and files

A file explorer, a terminal with the full ByteOS shell, and an HTML editor that saves straight to the ByteFS disk.

Small on purpose

No third-party bootloader, no libc, no networking stack. Every line is in the repository, from the MBR to the donut renderer.

Try it in QEMU

qemu-img create -f raw byteos-disk.img 64M
qemu-system-x86_64 -m 1024 -smp 4 \
  -cdrom ByteOS.iso \
  -drive file=byteos-disk.img,format=raw,if=ide \
  -boot d

Then run fetch, donut, or start-desktop to pick ByteDesktop, ByteWin 95 or ByteTile. To install, run byte-install and choose the 64 MiB disk.
